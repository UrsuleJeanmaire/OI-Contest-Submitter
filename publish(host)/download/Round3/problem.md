# T788943 A. 不知所谓的机器

## 题目描述

你发现了一台神秘的机器，这台机器可以让你输入一个正整数 $x$，接下来机器的屏幕上显示 $x$ 的每一数位上的数的乘积，例如当你输入 $x=114514$ 的时候，屏幕上就会出现 $1\times 1\times 4\times 5\times 1\times 4=80$。

机器对于输入的整数 $x$ 有限制，具体来说，你输入的整数 $x$ 必须满足 $l\leq x\leq r$。

如果屏幕上显示的乘积是所有合法 $x$ 对应的乘积中最大的，你就可以获得一颗水晶之心。

所以接下来你的任务就是输出一个使得乘积最大的 $x$，如果有多个符合条件的 $x$，你可以输出任意一个。

## 输入格式

本题有多组测试数据，第一行一个整数 $T$ 代表数据组数。

对于每组数据，输入两个整数 $l,r$ 代表合法的 $x$ 的范围。

## 输出格式

共 $T$ 行，每行输出一个 $x$ 代表合法的 $x$ 中可以使得乘积最大的一个，如果有多个符合条件的 $x$，你可以输出任意一个。

## 输入输出样例 #1

### 输入 #1

```
3
1 8
13 25
113 570
```

### 输出 #1

```
8
25
499
```

## 说明/提示

本题共 $10$ 个测试点，每个测试点 $10$ 分。

- 对于 $20\%$ 的数据，$T\leq 10,r\leq 10^5$。
- 对于 $40\%$ 的数据，$r\leq 10^5$。
- 对于另外 $10\%$ 的数据，$T\leq 5$，$[l,r]$ 随机生成。
- 对于另外 $10\%$ 的数据，$l=1$。
- 对于另外 $10\%$ 的数据，$r=10^k,k$ 是非负整数。
- 对于 $100\%$ 的数据，$1\leq T\leq 10^5,1\leq l\leq r\leq 10^{18}$。

# T788944 B. 踏脚石

## 题目描述

你来到了一片充满机关的房间，准备从左侧跳到右侧，下方则是万丈悬崖。

中间竖立着 $m$ 根柱子，第 $i$ 根位于从左到右 $a_i$ 米的地方，保证 $0<a_1<a_2\cdots <a_m<10^9$。

房间里有 $n$ 个开关控制着这些柱子，当第 $i$ 个开关被按下时，所有满足 $a_p\leq l_i$ 或者 $a_p\geq r_i$ 的柱子都会被摧毁，多个开关的效果可以叠加。

Badeline 想要阻止你通过房间，因此他会选择若干个开关按下，显然她一共有 $2^n$ 种不同的按开关的方案。而你能通过这个房间当且仅当存在至少 $k$ 个柱子没有被摧毁，请你求出所有方案中有多少个可以让你通过房间，求出方案数对 $998244353$ 取模的结果。

## 输入格式

第一行三个整数 $n,m,k$ 代表开关个数、柱子个数，至少不被摧毁的柱子个数。

接下来一行 $m$ 个整数 $a_1,a_2\cdots a_m$。

接下来 $n$ 行，每行一对整数 $l_i,r_i$。

## 输出格式

一行，一个非负整数代表合法方案数。

## 输入输出样例 #1

### 输入 #1

```
3 5 3
10 20 30 40 50
15 45
25 55
5 25
```

### 输出 #1

```
3
```

## 说明/提示

本题共 $20$ 个测试点，每个测试点 $5$ 分。

- 对于测试点 $1\sim 2$ 的数据，$n,m\leq 15$。
- 对于测试点 $3\sim 5$ 的数据，$n\leq 15$。
- 对于测试点 $6\sim 7$ 的数据，$n,m\leq 500$。
- 对于测试点 $8\sim 10$ 的数据，$n,m\leq 2000$。
- 对于测试点 $11\sim 13$ 的数据，$k=1$。
- 对于测试点 $14\sim 16$，所有 $[l_i,r_i]$ 随机生成。
- 对于测试点 $17\sim 20$ 的数据，无特殊限制。
- 对于 $100\%$ 的数据，$1\leq k\leq m,1\leq n,m\leq 3\times 10^5,1\leq l_i< r_i\leq 10^{9}$,$0<a_1<a_2\cdots <a_m<10^9$。

# T788945 C. 冰火两重天

## 题目描述

你被 8b 吓哭了。

这里有 $n$ 个关卡，每个关卡分成 “冰”与“火”两个部分，对应的难度分别是 $x_i,y_i$，数值越大难度越高。

保证 $\forall i\neq j,x_i\neq x_j,y_i\neq y_j$。

你喜欢从简单的关卡开始挑战，具体来说，你会按某种顺序依次完成 $n$ 个关卡，每一次从以下两种里选一个：

- 选择冰之难度 $x_i$ 最小的一个 $i$，花费 $a_i$ 的时间通过这一关。
- 选择火之难度 $y_i$ 最小的一个 $i$，花费 $b_i$ 的时间通过这一关。

被通过的关卡就会消失。

请问如果通过所有关卡的总用时最小是多少？

## 输入格式

第一行一个整数 $n$。

接下来 $n$ 行，每行四个整数 $x_i,y_i,a_i,b_i$。

## 输出格式

一行，一个非负整数代表通过所有关卡的最少用时。

## 输入输出样例 #1

### 输入 #1

```
3
10 30 5 100
20 10 100 20
30 20 15 50
```

### 输出 #1

```
40
```

## 说明/提示

- 对于 $10\%$ 的数据，$n\leq 20$。
- 对于 $25\%$ 的数据，$n\leq 200$。
- 对于 $40\%$ 的数据，$n\leq 2000$。
- 对于另外 $15\%$ 的数据，对于任意的 $i\neq j$，如果 $x_i<x_j$，那么 $y_i>y_j$。
- 对于另外 $15\%$ 的数据，$a_i=x_i,b_i=y_i$。
- 对于 $100\%$ 的数据，$1\leq n\leq 3\times 10^5,1\leq  a_i,b_i,x_i,y_i\leq 10^9$

# T788946 D.沉思

## 题目描述

给定一个长度为 $m$ 的字符串 $t$，记 $T_i$ 为 $t$ 的前 $i$ 个字符构成的字符串，即 $T_i=t_1t_2\cdots t_{i}$。

给定一棵 $n+1$ 个点的树，编号为 $0,1\cdots n$，其中 $0$ 是根，且每条边上都有一个字符。记 $s_i$ 是树上从根到 $i$ 的路径上的字符顺序连起来形成的字符串，$d_i$ 为 $s_i$ 的长度。

对于 $1\leq i\leq n,1\leq j\leq m$，定义 $f(i,j)$ 为所有满足如下条件的 $k$ 的 $d_k$ 的最大值：

- $0\leq k\leq n$。
- $s_k$ 是 $s_i+T_j$ 的后缀，其中 `+` 表示字符串拼接。

对于 $1\leq j\leq m$，定义 $g(j)=\sum\limits_{i=1}^nf(i,j)$，请你求出 $g(1),g(2)\cdots g(m)$。

注意，本题的字符不止 $26$ 个，因此我们用 $1,2\cdots $ 这样的正整数编号来指代每个字符。

## 输入格式

第一行包含两个正整数 $n, m$。

第二行包含 $n$ 个整数 $p_1, \dots, p_n$，其中 $p_i$ 表示第 $i$ 个点在树上的父亲。

第三行包含 $n$ 个整数 $c_1, \dots, c_n$，表示 $p_i$ 到 $i$ 的字符。

第四行包含 $m$ 个整数 $t_1, \dots, t_m$，表示字符串 $t$。

## 输出格式

一行，$m$ 个整数代表 $g(1),g(2)\cdots g(m)$。

## 输入输出样例 #1

### 输入 #1

```
4 3
0 1 0 3
1 2 2 1
2 1 2
```

### 输出 #1

```
6 8 8 
```

## 说明/提示

本题共有 $20$ 个测试点，每个测试点 $5$ 分。

对于测试点 $1\sim 2$，$n,m\leq 50,c_i,t_i\leq 26$。

对于测试点 $3\sim 5$，$m,m\leq 500,c_i,t_i\leq 26$。

对于测试点 $6\sim 8$，$n,m\leq 5000,c_i,t_i\leq 26$。


对于测试点 $9\sim 11$，$p_i=i-1,c_i,t_i\leq 26$。

对于测试点 $12\sim 15$，$c_i,t_i\leq 26$。

对于测试点 $16\sim 20$，无特殊限制。

对于 $100\%$ 的数据，$1\leq n,m\leq 2\times 10^5$，保证 $0\leq p_i<i$,$1\leq c_i,t_i\leq n$，且保证如果 $p_i=p_j$ 那么 $c_i\neq c_j$。
